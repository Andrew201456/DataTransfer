# DataTransfer — Αυτόματη μεταφορά αρχείων

Άνοιξε **το ίδιο URL της εφαρμογής** στο κινητό και στον υπολογιστή. Δεν χρειάζεται room code, link πρόσκλησης, login ή manual pairing. Όταν ανακαλυφθούν οι συσκευές, εμφανίζονται αυτόματα στην ίδια λίστα και μπορείς να πατήσεις **Αποστολή αρχείων** ή να σύρεις αρχεία πάνω στην κάρτα τους.

## Τι χρειάζεται

- Και οι δύο browsers να είναι ανοικτοί και online.
- Για **αυτόματη αναγνώριση**, οι συσκευές να βρίσκονται σε κοινό οικιακό/γραφειακό δίκτυο, ιδανικά στο ίδιο Wi‑Fi (ή PC με Ethernet στο ίδιο router).
- Δεν απαιτείται εγκατάσταση εφαρμογής ή port forwarding. Στο iPhone κράτα τη σελίδα ανοιχτή/μπροστά κατά τη μεταφορά.
- Η εφαρμογή δοκιμάζει πρώτα **WebRTC P2P** και, αν δεν συνδεθεί, **WebSocket relay μέσω Cloudflare**.

## Πώς γίνεται η ανακάλυψη χωρίς room

Ο browser συνδέεται αυτόματα στον υπάρχοντα Cloudflare Worker μέσω `/ws`. Ο Worker ομαδοποιεί προσωρινά συσκευές με την ίδια δημόσια IPv4 διεύθυνση ή το ίδιο IPv6 /64. Επιπλέον, προαιρετικά γίνεται WebRTC/STUN έλεγχος για την δημόσια IPv4 του δικτύου, ώστε να εντοπίζονται περιπτώσεις όπου το ένα browser μπαίνει στο Cloudflare με IPv6 και το άλλο με IPv4. Αυτή η διεύθυνση **γίνεται hash μέσα στον browser** πριν χρησιμοποιηθεί ως πρόσθετο discovery group. Δεν αποθηκεύεται κάποια δημόσια λίστα συσκευών.

**Τεχνικός περιορισμός:** Χωρίς κάποιο κοινό αναγνωριστικό ή λογαριασμό, μια web εφαρμογή **δεν μπορεί να εγγυηθεί** ότι θα αναγνωρίσει αυτόματα δύο συσκευές σε εντελώς άσχετα δίκτυα, ή όταν VPN, CGNAT, εταιρικό firewall ή ρυθμίσεις του browser κρύβουν όλα τα κοινά στοιχεία δικτύου. Η ανακάλυψη βάσει δημόσιας IP επίσης δεν πιστοποιεί ότι μια συσκευή είναι δική σου: άλλοι χρήστες πίσω από το ίδιο NAT (π.χ. δημόσιο Wi-Fi) μπορεί να εμφανιστούν. **Έλεγξε το όνομα του παραλήπτη πριν στείλεις κάτι.**

## Ασφάλεια & μεταφορές

- Τα δεδομένα **δεν αποθηκεύονται** στον Cloudflare Worker. Η σύνδεση WebRTC είναι κρυπτογραφημένη μεταξύ browsers.
- Όταν αποτυγχάνει το WebRTC, τα δεδομένα διέρχονται προσωρινά από Cloudflare Durable Object μέσω TLS/WSS. Το relay fallback **δεν** αποτελεί end-to-end κρυπτογραφημένη μεταφορά πέρα από TLS (το Cloudflare έχει πρόσβαση στα δεδομένα της ροής).
- Τα αρχεία φτάνουν στον browser του παραλήπτη και μένουν σε προσωρινή μνήμη (Blob URL). Πάτησε **Λήψη αρχείου** πριν κλείσεις τη σελίδα.
- Μέγιστο μέγεθος **256 MB ανά αρχείο** για προστασία της μνήμης του κινητού.
- Το interface εμφανίζει την πορεία και περιμένει επιβεβαίωση παραλαβής.
- Η χρήση relay επιβαρύνει την υποδομή Cloudflare και μπορεί να αυξήσει τη χρέωσή της.

## Αν δεν εμφανίζονται οι συσκευές

Δοκίμασε να συνδέσεις το PC και το κινητό στο **ίδιο Wi‑Fi/router**, να απενεργοποιήσεις προσωρινά VPN και να ανοίξεις ξανά και τις δύο σελίδες. Επίσης, σε ορισμένους browsers επιλέγεται περιοριστική πολιτική WebRTC ή μπλοκάρεται το STUN. Αν ένα δίκτυο εμποδίζει και WebSocket/WSS, δεν μπορεί να γίνει σύνδεση μέσω του Cloudflare fallback.

## Deploy

Το project χρησιμοποιεί `public/` για το static UI και `src/worker.js` για τον Cloudflare Worker και το Durable Object `ROOMS`. Το `wrangler.toml` παραμένει ως έχει.

```bash
npx wrangler deploy
```

Οι παλιές δωμάτια τύπου `dt-...` του DriveTunes συνεχίζουν να λειτουργούν για τις υπάρχουσες μεταφορές τους. Το DataTransfer δεν απαιτεί πια κάποιο room.

Οι δοκιμές βρίσκονται στο `tests/validate.mjs`. Έχουν γίνει προσομοιώσεις αυτόματου εντοπισμού και ολοκλήρωσης WebSocket μεταφοράς, αλλά οι πραγματικές διαφορετικές συνθήκες δικτύου χρειάζονται έλεγχο σε συσκευές.
