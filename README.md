# DataTransfer — Ασύρματη μεταφορά αρχείων

Μια responsive PWA για μεταφορά αρχείων και κειμένου από συσκευή σε συσκευή. Χωρίς λογαριασμό, με σύνδεση μέσω ιδιωτικού room και υποστήριξη διαφορετικών δικτύων.

## Χρήση

1. Άνοιξε την εφαρμογή στην πρώτη συσκευή. Δημιουργείται αυτόματα ένας τυχαίος 16-χαρακτήρων κωδικός.
2. Πάτησε **Κοινή χρήση** ή **Αντιγραφή link** και άνοιξε το link στη δεύτερη συσκευή. Εναλλακτικά, πληκτρολόγησε τον κωδικό από το πεδίο «Έχεις ήδη κωδικό;».
3. Οι συσκευές θα εμφανιστούν στην ενότητα **Συσκευές**. Πάτησε **Αποστολή αρχείων**, σύρε αρχεία πάνω στην κάρτα συσκευής ή στην κεντρική περιοχή αποστολής (όταν υπάρχει μία συνδεδεμένη συσκευή).
4. Στη συσκευή παραλήπτη πάτησε **Λήψη αρχείου** για αποθήκευση στα αρχεία της συσκευής.

Η σύνδεση παραμένει ενεργή όσο οι δύο σελίδες είναι ανοικτές. Η εφαρμογή δεν περιλαμβάνει συγχρονισμό ή μόνιμο cloud storage.

## Γιατί δεν βρίσκονταν πάντα αυτόματα οι συσκευές;

Η προηγούμενη **«Ίδιο δίκτυο»** λειτουργία χρησιμοποιούσε την εξωτερική IP του browser, κάτι που δεν αποτελεί αξιόπιστη ταυτότητα τοπικού δικτύου: IPv6, carrier-grade NAT, VPN, routers και network isolation μπορούν να δώσουν διαφορετικά identifiers σε συσκευές του ίδιου Wi-Fi.

Η νέα έκδοση βασίζεται σε **τυχαίο room code / invitation link** αντί για υποθέσεις για το δίκτυο. Έτσι γίνεται η ανακάλυψη μέσω Cloudflare Worker ακόμη κι αν οι συσκευές είναι σε διαφορετικά δίκτυα. Το room code λειτουργεί σαν μυστικό πρόσκλησης: **μην το κοινοποιείς δημόσια**. Για καινούργια σύνδεση, πάτησε **Δημιουργία νέας σύνδεσης**.

## Πώς ταξιδεύουν τα αρχεία

- **WebRTC DataChannel (P2P):** Πρώτη επιλογή. Ο ήχος/φωτογραφίες/αρχεία μεταφέρονται απευθείας ανάμεσα στις συσκευές, με το Cloudflare να διαχειρίζεται μόνο τα μηνύματα signaling.
- **WebSocket fallback:** Αν το WebRTC δεν συνδεθεί μέσα σε περίπου 8,5 δευτερόλεπτα (π.χ. λόγω αυστηρού firewall ή CGNAT), ο browser στέλνει τα chunks μέσω του Cloudflare Durable Object, ο οποίος τα προωθεί στη συσκευή παραλήπτη **χωρίς να τα αποθηκεύει**. Το UI δείχνει «Σύνδεση μέσω Cloudflare». Αυτό απαιτεί να επιτρέπεται ασφαλές WebSocket/WSS από το δίκτυο.
- **Ασφάλεια:** Το WebRTC κρυπτογραφεί το DataChannel. Το fallback επικοινωνεί με Cloudflare μέσω TLS/WSS, αλλά τα chunks περνούν από τον Cloudflare Worker και **δεν** έχουν επιπλέον client-side end-to-end encryption. Μην θεωρείς το fallback πλήρως E2EE.
- **Flow control:** Χρησιμοποιούνται chunks 32 KiB, backpressure/confirmations και τελική επιβεβαίωση από τον παραλήπτη, όχι απλώς ολοκλήρωση upload στον browser.
- **Όριο:** Έως 256 MB ανά αρχείο. Ο παραλήπτης δημιουργεί προσωρινό Blob URL στη μνήμη του browser. Τα ληφθέντα αρχεία μπορούν να χαθούν αν κλείσεις τη σελίδα πριν πατήσεις **Λήψη αρχείου**. Μεγάλα αρχεία μπορεί να καταναλώσουν αρκετή RAM στο κινητό.

Οι μεταφορές μπορεί να επιβαρύνουν με χρεώσεις χρήσης Workers/Durable Objects όταν χρησιμοποιείται το relay fallback. Το Cloudflare endpoint δεν είναι γενικό storage ή CDN.

## Cloudflare deployment

Το υπάρχον `wrangler.toml` και το binding `ROOMS` χρησιμοποιούνται χωρίς αλλαγές.

```bash
npm exec wrangler deploy
```

Το project είναι στατικό HTML/CSS/JS μέσα στο `public/` και Worker/Durable Object στο `src/worker.js`. Το Worker υποστηρίζει επίσης τις υπάρχουσες `dt-...` rooms του DriveTunes για signaling.

## Πιθανά προβλήματα

- **Δεν εμφανίζεται η άλλη συσκευή:** Και οι δύο πρέπει να έχουν τον ίδιο κωδικό στο URL, ανοιχτή τη σελίδα και να εμφανίζει η εφαρμογή «Έτοιμο για σύνδεση». Δοκίμασε να ανοίξεις ξανά το invitation link.
- **Βρίσκονται αλλά η απευθείας αποστολή δεν λειτουργεί:** Περίμενε την εναλλακτική σύνδεση Cloudflare και έλεγξε αν το δίκτυο επιτρέπει WebSocket μέσω HTTPS. Αν μπλοκάρει και το WSS, δεν μπορεί να λειτουργήσει το fallback.
- **Κινητό / iPhone:** Κράτα την εφαρμογή σε πρώτο πλάνο μέχρι να ολοκληρωθεί η αποστολή ή λήψη. Κατά τη διάρκεια ενός μεγάλου αρχείου μην κλειδώσεις την οθόνη.
- **Παλιά εμφάνιση:** Κλείσε την εγκατεστημένη PWA και ξανάνοιξέ την ώστε να ενημερωθεί το Service Worker.
- **Πολύ μεγάλα αρχεία:** Το όριο προστατεύει την RAM του browser. Για σημαντικά μεγαλύτερα αρχεία χρειάζεται άλλη αρχιτεκτονική λήψης, π.χ. streaming σε File System Access API όπου υποστηρίζεται.

## Σημειώσεις για development

Το repository διατηρεί το ίδιο Cloudflare Worker routing και τα Durable Objects. Δες `tests/validate.mjs` για βασικούς στατικούς ελέγχους και προσομοιώσεις signaling/relay. Οι πραγματικές μεταφορές χρειάζονται δοκιμή σε τουλάχιστον δύο browsers / δίκτυα.
